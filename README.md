# مَدار V0 — المساعد المحاسبي للمدارس

نظام مساعد شخصي لخدمة محاسبي المدارس (50–75 مدرسة ومستخدماً في المرحلة الأولى). **ليس نظاماً حكومياً رسمياً.**
V0 هو إعادة هيكلة النسخة التجريبية 0.2.0 مع الإبقاء على قاعدة البيانات والاختبارات، وإدماج النماذج المعتمدة والشعار والقواعد المالية.

## ما الجديد في V0

| المجال | ما يعمل |
|---|---|
| الغرامات | أيام **عمل** (الأحد–الخميس) مع استبعاد **الإجازات الرسمية** من مدة التوريد وأيام التأخير؛ 1% عن كل يوم عمل وبحد أقصى 10%. شاشة لإدارة الإجازات السنوية. |
| سياسة الشراء | حتى 1000 ر.ق عرض سعر واحد؛ أكثر من ذلك 3 عروض على الأقل إلا إذا كان المورد **محتكراً** (مع المبرر)؛ أكثر من 200,000 ر.ق مناقصة من اختصاص إدارة المشتريات بالوزارة. كل القيم قابلة للتعديل من شاشة **السياسة المالية** بتاريخ سريان، دون تغيير المعاملات السابقة. |
| العهد | النثرية: قيمة العهدة تُطلب عند كل فتح، والاستعاضة عند صرف **75%** (قابلة للتعديل)، وفاتورة النثرية حتى حد العرض الواحد. عهدة يوم التعليم ومعرض الكتاب والخاصة: تسوية وإغلاق. شاشة تسوية تعرض كامل بيانات العهدة وتسأل: استعاضة أم إغلاق. |
| النماذج المطبوعة | بترويسة الوزارة وحسب ملفات Excel المعتمدة: تقرير دراسة عروض الأسعار، كتاب التكليف / أمر الشراء المحلي، شهادة إنجاز أعمال (مع تقييم المورد والمرفقات)، كتاب التغطية لصرف المستحقات، كشف استعاضة النثرية وكتاب تغطيته، الموازنة التقديرية. المبالغ **تفقيطاً** بالريال القطري. |
| الموازنة | دليل البنود الرسمية بأرقام الحسابات، توزيع مبنى المدرسة / مبنى الروضة، الافتراضات (الطلاب والهيئات)، وطباعة الموازنة التقديرية. |
| البحث والتقارير | سجل شهادات الإنجاز عبر كل مدارس المحاسب: بحث بالمورد والمدرسة والرقم والفترة، إعادة طباعة، تصدير Excel. تقارير المعاملات المحفوظة. |
| لوحة مدير النظام | يرى مدير النظام كل المدارس وكل الحسابات: المنجز وقيد الإعداد لكل حساب، الاعتمادات والشهادات وفواتير العهد وآخر دخول، مع **تقرير أعمال لكل حساب** (عرض، طباعة، PDF، Excel) وإدارة الحسابات: إعادة تعيين كلمة المرور، الإيقاف والتفعيل، الصلاحيات لكل مدرسة. الدخول باسم مستخدم وكلمة مرور يحددهما مدير النظام. |
| PDF | تصدير كل النماذج إلى PDF من الخادم بخطوط عربية مضمنة (Noto Naskh / Noto Kufi) وتنسيق A4 احترافي وترقيم الصفحات؛ الخطابات وشهادة الإنجاز في صفحة واحدة. |
| الشعار | شعار الوزارة الجديد في شاشات النظام، وترويسة الوزارة في كل التقارير المطبوعة. |
| المكتبة | بند المكتبة على حساب المصروف 510201، وشراء الكتب يُقيد على حساب الأصل 110805 من نفس البند، ويظهر كل حساب منفصلاً في ملخص كشف النثرية. |
| الكود | تقسيم إلى طبقات ووحدات منظمة (انظر «بنية المشروع»)، وتنسيق موحد بـ Prettier. 30 اختباراً آلياً. |

لقطات الشاشات والنماذج المطبوعة: [`docs/screenshots`](docs/screenshots)، ونماذج PDF: [`docs/screenshots/pdf`](docs/screenshots/pdf).

## تشغيل سريع للتجربة — Node.js 22.12+ أو 24

```bash
npm ci
npm run build
DEMO_PASSWORD='ضع-كلمة-مرور-قوية-للتجربة' npm run demo
```

في PowerShell: `$env:DEMO_PASSWORD="..."; npm run demo`. افتح `http://localhost:3000` (استخدم localhost وليس 127.0.0.1).

| الحساب | الاستخدام |
|---|---|
| accountant | محاسب المدرسة الأولى: المعاملات والتوريدات والمستندات وفواتير العهد |
| approver | معتمد / مراجع / مسجل ERP للمدرسة الأولى |
| admin | مدير النظام: لوحة مدير النظام، المدارس والحسابات والإجازات والسياسة المالية ودليل الموازنة |
| other | محاسب مدرسة ثانية للتحقق من عزل المدارس |

البيانات التجريبية اصطناعية وتُحفظ في `.data/demo`. لبدء بيانات جديدة احذف المجلد وأعد التشغيل.

## النشر على خادم سحابي بدومين خاص

```bash
cp .env.example .env        # DOMAIN, DB_PASSWORD, ADMIN_USERNAME, ADMIN_NAME, ADMIN_PASSWORD
docker compose -f docker-compose.yml -f deploy/docker-compose.prod.yml up --build -d
docker compose -f docker-compose.yml -f deploy/docker-compose.prod.yml run --rm api npm run bootstrap
```

- يوجّه سجل DNS للدومين إلى الخادم، ويصدر Caddy شهادة HTTPS تلقائياً (المنفذان 80 و443).
- `bootstrap` يعمل مرة واحدة على قاعدة فارغة: ينشئ مسؤول النظام ودليل بنود الموازنة. بعدها أضف المدارس والمستخدمين من «الإعدادات» والإجازات من «الإجازات الرسمية».
- الصورة تتضمن Chromium لتصدير PDF، وClamAV لفحص المرفقات (إلزامي خارج وضع التجربة). أعد بناء الصورة دورياً لتحديث التواقيع.
- راجع [`docs/security-and-operations.md`](docs/security-and-operations.md) للنسخ الاحتياطي والاستعادة.

## بنية المشروع

```
apps/api/src
  main.ts                 تشغيل NestJS، الحماية ومعالجة الأخطاء
  http/controllers.ts     المسارات: auth، schools/:school/*، registry، admin/*
  common/                 قاعدة البيانات، التحقق، المال، التواريخ وتقويم أيام العمل
  core/                   الهوية والصلاحيات، المعاملات الذرية والتدقيق، القيد على الموازنة،
                          الغرامة، السياسة المالية، التفقيط، قائمة المستندات
  modules/                router.ts يوزع الطلبات على: school، suppliers، budgets، imprests،
                          reports، tenant (الإدارة)، cases/ (procurement، fulfilment، read)
  print/                  النماذج المطبوعة: layout (الترويسة والخطوط)، procurement، certificate، imprest، budget
  core/pdf.ts             تصدير PDF من الخادم (Chromium)
  modules/admin.ts        لوحة مدير النظام وتقرير أعمال كل حساب وإدارة الحسابات
apps/web
  components/             App (الإطار والدخول)، FormDialog، ui، context
  views/                  شاشة لكل قسم: Dashboard، Cases، CaseDetail، Imprests، Budget، Registry،
                          Holidays، Policy، Suppliers، Reports، Settings، Audit، AdminConsole
  lib/                    عميل API والتنسيق
  public/brand/           شعار الوزارة (الشاشات) وترويسة التقارير
  public/fonts/           خطوط Noto العربية (رخصة OFL)
prisma/                   المخطط والترحيلات (القيود المالية والسجل غير القابل للتعديل)
scripts/                  demo، seed (تجريبي)، bootstrap (إنتاج)، catalog (البنود الرسمية)، ui-walkthrough
tests/                    اختبارات النظام
```
