# حالة التسليم — V0

الحالة: **جاهز للتجربة الفعلية المحدودة بعد النشر، مع البوابات أدناه**.

## ما تم التحقق منه (28 سبتمبر 2026)

- `npm run typecheck` و`npm run build` بنجاح.
- `npm test`: **30 اختباراً ناجحاً** (منها: لوحة مدير النظام وتقرير الحساب، إعادة تعيين كلمة المرور والإيقاف والصلاحيات، حساب الأصل للمكتبة، تصدير PDF)، ومن قبلها (17 من النسخة 0.2.0 محدّثة لأيام العمل، و9 جديدة): التفقيط، النماذج المطبوعة، سياسة الشراء (عرض واحد / 3 عروض / محتكر / مناقصة)، الإجازات، السياسة المالية بتاريخ سريان وسجل غير قابل للتعديل، سجل الشهادات عبر المدارس مع العزل، الموازنة وتوزيع المدرسة/الروضة، عهدة النثرية وحد 75% وحد الفاتورة، عهدة معرض الكتاب، التنبيهات.
- جولة متصفح آلية (Chromium) على نسخة تجريبية: دورة شراء كاملة وتسوية نثرية، مع لقطات لكل الشاشات والنماذج في `docs/screenshots`.
- `npm audit`: لا ثغرات معروفة في الاعتماديات وقت الفحص.

الاختبارات تستخدم PGlite (محرك PostgreSQL) باتصال واحد؛ لا تعادل اختبار تزامن على خادم PostgreSQL متعدد الاتصالات.

## قرارات مؤكدة من صاحب النظام

1. الغرامة 1% عن كل يوم عمل من قيمة **الجزء المتأخر**، بحد أقصى 10%.
2. فاتورة النثرية حتى 1000 ر.ق؛ ما يزيد يتطلب عروض أسعار.
3. المكتبة: 510201 حساب مصروف، و110805 حساب أصل (الكتب).
4. سلسلة الاعتماد: محاسب ثم معتمد، دون مستويات إضافية.
5. ERP تسجيل يدوي.
6. الدخول بخطوة واحدة: اسم مستخدم وكلمة مرور يحددهما مدير النظام.
7. شعار الوزارة إلزامي في التقارير، والشعار الجديد في الشاشات.
8. التصدير المعتمد PDF.
9. رقم حساب «مواد مسار مهني»: 10001.

## بوابات قبل الاستخدام بالبيانات الحقيقية

1. النشر على الخادم بـ HTTPS (`deploy/`) وتشغيل `bootstrap`، ثم إدخال المدارس والإجازات الرسمية للعام.
2. اختبار نسخ احتياطي واستعادة فعلي يشمل المرفقات (`docs/security-and-operations.md`).
3. التأكد من عمل فحص المرفقات (ClamAV) داخل الحاوية: رفع ملف PDF سليم ومراجعته.
4. مراجعة الطباعة على الطابعة الفعلية (A4) لكل نموذج.

## خارج نطاق V0
