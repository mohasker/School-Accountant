# حالة التسليم — 0.2.0

الحالة: **نسخة تجريبية قابلة للتشغيل واختبار القبول، غير معتمدة للإنتاج**.

## ما تم التحقق منه

بتاريخ 25 سبتمبر 2026: نجح البناء ونجحت الاختبارات الـ17. أعاد npm audit صفراً من الثغرات المعروفة للاعتماديات المثبتة؛ هذه نتيجة فحص اعتماديات وليست ضماناً أمنياً للتطبيق.

بدأ خادم الواجهة بنجاح، لكن اختبار المتصفح الآلي توقف بسبب منع البيئة عملية chown لملفات خطوط Chromium. لذلك لم يُستكمل الفحص البصري والتفاعلي، ولا توجد لقطات واجهة معتمدة في التسليم. السكربت scripts/browser-qa.ts مرفق لإعادة الاختبار في بيئة مناسبة.

راجع ملف نتائج الاختبارات المرفق. تغطي المجموعة الحسابات الدقيقة، عزل المدارس، CSRF، إبطال الجلسة، الموردين، دورة منافسة كاملة مع توريدين وشهادتين، المستندات، التغطية وERP، التكاليف الوزارية، الموازنة، العهد والتقارير وقيود قاعدة البيانات.

اختبارات API تستخدم PGlite/محرك PostgreSQL مع خادم بروتوكول PostgreSQL وPrisma، بحد اتصال واحد. اختبار طلبين متزامنين يثبت سلامة السلوك ضمن هذه البيئة فقط؛ لا يعادل اختبار تنافس معاملات على خادم PostgreSQL متعدد الاتصالات.

## غير مكتمل مقارنة بالبرومبت V1.1

- اعتماد وربط النماذج الرسمية والشعار وقائمة بنود الموازنة.
- الحفظ التلقائي، مركز التنبيهات وقائمة المهام المخصصة لكل مستخدم.
- استيراد Excel لبنود الموازنة والمدارس؛ المتاح حالياً استيراد الموردين CSV وإدخال الموازنة يدوياً.
- نقل الاعتمادات بين البنود كدورة مستقلة، وإجراءات التصحيح/الإلغاء بعد الاستلام أو التسجيل الوزاري.
- عطلات وأيام عمل وسياسات غرامة بديلة. المتاح سياسة أيام تقويمية وتاريخ التسليم المقبول.
- تحميل فواتير العهد كملفات مرتبطة ومراجعتها؛ المتاح مرجع دليل الفاتورة نصياً.
- أنواع تقارير مستقلة موسعة لكل الكيانات؛ المتاح تقرير معاملات محفوظ وكشوف تفاعلية للموازنة والعهد.
- MFA، تخزين خاص خارجي، فحص مؤسسي للمرفقات، ومراقبة تشغيل مركزية.
- فصل الملفات الطويلة إلى وحدات مجال أصغر وتحسين إتاحة الحوارات بلوحة المفاتيح قبل الإصدار النهائي.

## بوابات إلزامية قبل الاستخدام الحقيقي

1. مراجعة واعتماد سياسة الغرامة والمدة وأساس إثبات المصروف، من صاحب الصلاحية؛ القاعدة الحالية من طلب المستخدم وليست تأكيداً قانونياً.
2. إدماج النماذج الرسمية ومراجعة الطباعة العربية لجميع أحجام المستندات.
3. تشغيل Docker والاختبارات على PostgreSQL خادمي مستقل، وفحص التزامن عبر اتصالات متعددة ومجموعات بيانات أكبر.
4. فصل أدوار الهجرة ومالك القاعدة وحساب تشغيل التطبيق؛ لا تستخدم مالك القاعدة في الإنتاج. تفعيل RLS ومراجعة التغطية؛ العزل الحالي في الخدمة والقيود المركبة، لا توجد سياسة RLS مكتملة.
5. HTTPS وملفات أسرار مؤسسية، وسياسة كلمات مرور وMFA وإلغاء مستخدمين، وتحديد طلبات موزع عند تشغيل أكثر من نسخة.
6. فحص المرفقات: في غير وضع التجربة يفشل الرفع إذا لم ينجح ClamAV. صورة Docker الحالية لا تثبت ClamAV؛ يلزم توفيره وفحص ملفات تالفة/خبيثة وقيود التحميل.
7. اختبار نسخ احتياطي واستعادة فعلي يشمل المرفقات والمستندات. لم يُنفذ اختبار استعادة في هذه النسخة.
8. مراجعة الاعتماديات وفق ملف الفحص؛ لا تُفسر تعذر الحصول على نتيجة فحص بأنه عدم وجود ثغرات.
9. بوابة إصدار الشهادات الرسمية متوقفة خارج وضع التجربة. لا يكفي تغيير متغير بيئة لاعتماد القوالب قانونياً أو مؤسسياً.

هذه الحزمة لا تدعي تنفيذ كل اختبارات القبول الـ48 الواردة في المواصفات. نتائج الاختبارات المنفذة منفصلة ومرفقة.
