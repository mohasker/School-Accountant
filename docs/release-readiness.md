# حالة التسليم — V0

الحالة: **جاهز للتجربة الفعلية المحدودة بعد النشر، مع البوابات أدناه**.

## ما تم التحقق منه (28 سبتمبر 2026)

- `npm run typecheck` و`npm run build` بنجاح.
- `npm test`: **26 اختباراً ناجحاً** (17 من النسخة 0.2.0 محدّثة لأيام العمل، و9 جديدة): التفقيط، النماذج المطبوعة، سياسة الشراء (عرض واحد / 3 عروض / محتكر / مناقصة)، الإجازات، السياسة المالية بتاريخ سريان وسجل غير قابل للتعديل، سجل الشهادات عبر المدارس مع العزل، الموازنة وتوزيع المدرسة/الروضة، عهدة النثرية وحد 75% وحد الفاتورة، عهدة معرض الكتاب، التنبيهات.
- جولة متصفح آلية (Chromium) على نسخة تجريبية: دورة شراء كاملة وتسوية نثرية، مع لقطات لكل الشاشات والنماذج في `docs/screenshots`.
- `npm audit`: لا ثغرات معروفة في الاعتماديات وقت الفحص.

الاختبارات تستخدم PGlite (محرك PostgreSQL) باتصال واحد؛ لا تعادل اختبار تزامن على خادم PostgreSQL متعدد الاتصالات.

## قرارات بحاجة لتأكيدك

1. **أساس الغرامة في الشهادة**: النظام يحسب 1% من قيمة **الجزء المتأخر** (يطابق ملف Excel عند التوريد الكامل دفعة واحدة، ويكون أدق عند التوريد الجزئي).
2. **رقم حساب «مواد مسار مهني»** غير وارد في الملفات؛ مسجل مؤقتاً `CAREER`.
3. **المكتبة**: استُخدم الحساب `110805` كما في ملخص كشف النثرية (وليس `510201` الوارد في قائمة الحسابات الجانبية).
4. **فاتورة النثرية فوق 1000 ر.ق** مرفوضة (للنثرية فقط؛ عهدة يوم التعليم ومعرض الكتاب بدون هذا الحد).

## بوابات قبل الاستخدام بالبيانات الحقيقية

1. النشر على الخادم بـ HTTPS (`deploy/`) وتشغيل `bootstrap`، ثم إدخال المدارس والإجازات الرسمية للعام.
2. اختبار نسخ احتياطي واستعادة فعلي يشمل المرفقات (`docs/security-and-operations.md`).
3. التأكد من عمل فحص المرفقات (ClamAV) داخل الحاوية: رفع ملف PDF سليم ومراجعته.
4. موافقة الجهة المعنية على استخدام الشعار في موقع منشور، لأن النظام غير رسمي.
5. مراجعة الطباعة على الطابعة الفعلية (A4) لكل نموذج.
