# دليل الاستخدام — مَدار V0

## أول مرة (مسؤول النظام)

1. **الإعدادات ← المدارس**: أضف المدارس (الاسم، المدير، مسؤول العهدة النثرية، رمز أوامر الشراء مثل `MBAM`).
2. **إسناد مستخدم**: أضف المحاسب لكل مدرسة يخدمها، والمعتمد (مدير المدرسة أو من يفوضه)، مع الصلاحيات.
3. **الإجازات الرسمية**: أدخل إجازات العام (اليوم الوطني، الأعياد، إجازة الربيع…) كفترات من – إلى.
4. **السياسة المالية**: راجع القيم (حد العرض الواحد 1000، 3 عروض، حد المناقصة 200,000، الغرامة 1% / 10%، الاستعاضة 75%). عند صدور تعميم جديد عدّل القيمة بتاريخ سريانها.
5. **الموازنة ← إضافة البنود الرسمية** لكل مدرسة، ثم اعتماد مبلغ كل بند (مبنى المدرسة / مبنى الروضة).

## دورة الشراء

1. **معاملة شراء جديدة**: الموضوع والأصناف والكميات وبند الموازنة لكل صنف.
2. **عروض الأسعار**: رقم العرض وتاريخه والسعر لكل صنف والرأي الفني.
   - حتى 1000 ر.ق: عرض واحد يكفي.
   - أكثر من 1000: ثلاثة عروض على الأقل، أو عرض واحد مع ذكر **مبرر احتكار المورد**.
   - أكثر من 200,000: يرفض النظام؛ الشراء بمناقصة عبر إدارة المشتريات.
3. **اختيار العرض** ← يمكن **معاينة تقرير الدراسة** قبل الاعتماد.
4. **الاعتماد** بمستخدم غير معد المعاملة، ثم يُحفظ تقرير الدراسة بصيغته النهائية.
5. **إصدار كتاب التكليف**: التاريخ ومدة التوريد **بأيام العمل**؛ يحسب النظام آخر موعد مستبعداً الجمعة والسبت والإجازات. رقم أمر الشراء تلقائي (`الرمز/السنة-الشهراليوم`) أو يدوي.
6. **تسجيل التوريد**: التاريخ الفعلي، إذن التسليم، الفاتورة، الكميات المستلمة والمقبولة. التأخير يُحسب بأيام العمل بعد آخر موعد.
7. **المستندات المؤيدة**: ارفعها وتُراجع بمستخدم آخر. ما لا ينطبق (مثل موافقة القسم المختص) يُسجل «لا ينطبق» مع السبب.
8. **شهادة إنجاز الأعمال** (جزئية أو نهائية): الجهة الموجهة إليها، رقم الفاتورة، تقييم المورد في البنود الثلاثة، الملاحظات. الغرامة وصافي الفاتورة وتفقيطه تُحسب تلقائياً.
9. **كتاب التغطية**: اختر المرفقات المرسلة، ثم اطبع.
10. ارفع النسخ الموقعة من الشهادة وكتاب التغطية ← **تأكيد اكتمال الملف** ← **تسجيل ERP** (رقم القيد يدوياً).

## العهد

- **فتح عهدة**: النوع (نثرية / يوم التعليم / معرض الكتاب / خاصة)، المسؤول، والقيمة المستلمة — تُطلب في كل مرة.
- **فاتورة**: المورد، رقم الفاتورة (أو ملاحظة مثل «ليس لديهم فاتورة إلكترونية»)، التاريخ، البيان، البند، المبلغ. فاتورة النثرية حتى 1000 ر.ق.
- **تسوية / استعاضة / إغلاق**: تعرض الشاشة قيمة العهدة والرصيد والمنصرف غير المسوى وحد الاستعاضة، ثم تختار:
  - **تسوية واستعاضة** (للنثرية بعد بلوغ 75%).
  - **تسوية وإغلاق** (لكل الأنواع).
  يصدر **كشف الاستعاضة** بالترقيم (كشف رقم 1، 2 …) وملخص حسب أرقام الحسابات، و**كتاب التغطية** لمدير إدارة الشؤون المالية والإدارية.
- بعد التسوية: إثبات ERP، ثم **استلام الاستعاضة** (يعيد الرصيد) أو **إغلاق العهدة** بإيصال إعادة الرصيد المتبقي.

## البحث وإعادة الطباعة

- **شهادات الإنجاز**: ابحث بالمورد أو المدرسة أو رقم الشهادة / أمر التوريد / الفاتورة أو الفترة، ثم أعد طباعة الشهادة أو كتاب التغطية، أو نزّل السجل Excel.
- **التقارير**: تقرير المعاملات لفترة (يُحفظ ويمكن إعادة طباعته)، الموازنة التقديرية.

## الطباعة

كل زر طباعة يفتح النموذج في نافذة جديدة بترويسة الوزارة. من المتصفح اختر الطابعة أو «حفظ كـ PDF». النماذج الصادرة تُحفظ كما هي ولا تتغير إذا عُدلت بيانات المورد أو المدرسة لاحقاً.
