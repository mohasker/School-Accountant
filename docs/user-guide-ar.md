# دليل الاستخدام — MOESAS V0

## الشاشة الرئيسية

بعد اختيار **المدرسة** و**العام المالي** من أعلى الشاشة تظهر:
- **الموازنة والأرصدة**: المعتمد، المصروف، الارتباطات (تكليفات قائمة)، والرصيد المتاح، مع رسم لرصيد كل بند.
- **المستندات الصادرة خلال الفترة**: تقارير عروض الأسعار، التكليفات، شهادات الإنجاز (الصافي والغرامات)، كتب التغطية، فواتير العهد وتسوياتها.
- **الفترة**: العام كاملاً أو الربع أو الشهر الحالي أو من – إلى.
- **القيم الشهرية** (رسم بياني) و**مسار المعاملات** حسب المرحلة، والتنبيهات (تأخر التنفيذ، بلوغ حد الاستعاضة).

## المعاملة في أربعة مستندات

1. **تقرير عروض الأسعار** — «معاملة جديدة»: الموضوع والأصناف والكميات وبند الموازنة، ثم «إدخال عروض الأسعار»: **اسم الشركة وقيمة عرضها فقط** (رقم العرض اختياري)، صف لكل شركة. الشركة الجديدة تُضاف لدليل الموردين تلقائياً.
   - زر **«إصدار التقرير ← التكليف»**: يُكلَّف الأقل سعراً أو الشركة الوحيدة، ويصدر التقرير، وتفتح شاشة إعداد التكليف مباشرة. إذا كان في المعاملة أكثر من صنف يطلب النظام قيمة كل صنف للشركة المختارة (مجموعها = قيمة العرض).
   - حتى 1000 ر.ق عرض واحد يكفي؛ فوقها 3 عروض أو مبرر احتكار؛ فوق 200,000 من اختصاص إدارة المشتريات بالوزارة.
2. **كتاب التكليف** — التاريخ ومدة التنفيذ **بأيام العمل** (تُستبعد الجمعة والسبت والإجازات الرسمية).
3. **شهادة الإنجاز** و 4. **كتاب التغطية** — «إعداد الشهادة والتغطية» بعد إتمام المعاملة: تاريخ الإنجاز، رقم الفاتورة، التقييم، ومرفقات كتاب التغطية؛ الغرامة تُحسب تلقائياً.

**لوحة المستندات الجانبية** في صفحة المعاملة تعرض المستندات الأربعة، ولكل مستند: **طباعة** مباشرة، **PDF**، و**إرسال** بالبريد الإلكتروني أو واتساب (على الجوال وWindows يُرفق ملف PDF تلقائياً؛ وإلا يُنزَّل الملف وتُفتح الرسالة لإرفاقه). وفيها رابط **نظام ERP الوزارة** وتسجيل رقم القيد.

**قائمة المعاملات**: لكل معاملة زر للخطوة التالية (إكمال التقرير / إعداد التكليف / إعداد الشهادة والتغطية) وقائمة **طباعة** لإعادة طباعة أي مستند صدر.

## العهد

- **عهدة جديدة**: النوع (نثرية / يوم التعليم / معرض الكتاب / خاصة)، الاسم، المسؤول، **القيمة المستلمة**، ومرجع التمويل.
- **فاتورة**: المورد، رقم الفاتورة (أو ملاحظة مثل «ليس لديهم فاتورة إلكترونية»)، التاريخ، البيان، البند، المبلغ. فاتورة النثرية حتى 1000 ر.ق. لشراء كتب المكتبة فعّل «شراء أصل» ليُقيد على الحساب 110805.
- **تسوية / استعاضة + كتاب التغطية**: تعرض الشاشة قيمة العهدة والرصيد والمنصرف غير المسوى وحد الاستعاضة، ثم تختار **تسوية واستعاضة** (النثرية بعد بلوغ 75%) أو **تسوية وإغلاق**. يصدر **كشف التسوية** و**كتاب التغطية** معاً.
- بعدها: **استلام الاستعاضة** (يعيد الرصيد) أو **إغلاق العهدة** بإيصال إعادة الرصيد المتبقي.

## الإعدادات (لكل مستخدم)

- **بيانات المدرسة**: الاسم، المدير، مسؤول العهدة النثرية وعهدة يوم التعليم ومعرض الكتاب، **مسؤول المشتريات** (يوقع تقرير عروض الأسعار)، ورمز أوامر الشراء.
- **إضافة مدرسة**: تُضاف لمدارسك مباشرة ويُفتح لها العام الحالي ببنود الموازنة الرسمية.
- **إضافة عام مالي**، **الإجازات الرسمية** (إضافة وحذف)، و**تغيير كلمة المرور**.
- **ألوان النظام**: أنماط جاهزة أو لون رئيسي ولون قائمة جانبية من اختيارك (يُحفظ على الجهاز).
- المحاسب لا يرى حسابات المحاسبين الآخرين ولا يضيف مستخدمين؛ ذلك لمدير النظام فقط.

## مدير النظام

له **كامل الصلاحيات** على كل المدارس والحسابات:
- **لوحة مدير النظام**: كل الحسابات وأعمالها المنجزة وقيد الإعداد، و**تقرير الأعمال** لأي حساب (عرض، طباعة، PDF، Excel).
- إدارة الحسابات: حساب جديد، الصلاحيات لكل مدرسة، إعادة تعيين كلمة المرور، إيقاف / تفعيل، حذف (للحساب بلا أعمال).
- **السياسة المالية ودليل البنود** (تظهر له فقط): تعديل القيم بتاريخ سريان، وإضافة أو تعديل بنود الموازنة وأرقام الحسابات.
- **مسح البيانات**: حذف معاملة أو عهدة (تعود مبالغها لأرصدة البنود)، حذف مدرسة بكل بياناتها، أو مسح كل المعاملات والعهد، أو كل البيانات. يطلب النظام كتابة كلمة «حذف» للتأكيد.

## البحث وإعادة الطباعة

- **شهادات الإنجاز**: بحث بالمورد أو المدرسة أو رقم الشهادة / أمر التوريد / الفاتورة أو الفترة، إعادة طباعة الشهادة أو كتاب التغطية، وتصدير Excel.
- **التقارير**: تقرير المعاملات لفترة، والموازنة التقديرية.

## الطباعة وPDF

**طباعة** يفتح النموذج بترويسة الوزارة، و**PDF** ينزّل ملفاً معداً على الخادم بخط Calibri للأرقام وArial للعربي. النماذج الصادرة تُحفظ كما هي ولا تتغير إذا عُدلت بيانات الشركة أو المدرسة لاحقاً.
