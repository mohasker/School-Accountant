# التجربة بالرابط المباشر — لحين النشر على خادم

ثلاث طرق، كلها **لبيانات التجربة فقط**. البيانات الحقيقية تبقى على جهازك أو على الخادم الرسمي بعد النشر.

## 1) من GitHub مباشرة (Codespaces) — بدون أي تثبيت

افتح هذا الرابط من أي متصفح (كمبيوتر أو تابلت):

**https://codespaces.new/mohasker/School-Accountant?quickstart=1**

- سجّل الدخول بحساب GitHub، ثم «Create codespace».
- أول مرة: 3–5 دقائق للتجهيز، ثم يفتح النظام وحده في تبويب جديد (رابط ينتهي بـ `-3000.app.github.dev`).
- الدخول: `admin` أو `accountant` أو `supervisor` — كلمة المرور `Madar-Trial-2026`.
- المرات التالية: من github.com/codespaces اضغط على نفس الـ Codespace فيعود ببياناته.

**مشاركة الرابط مع زميل:** الرابط خاص بحسابك على GitHub افتراضياً. إن أردت أن يفتحه آخرون: في نافذة الـ Codespace ← تبويب **PORTS** ← المنفذ **3000** ← زر الفأرة الأيمن ← **Port Visibility ← Public**، ثم انسخ العنوان من نفس السطر. هذا قرارك أنت؛ الرابط العام يفتحه أي شخص يملكه (بيانات تجربة فقط). أعده إلى Private بعد الانتهاء.

**حدود مجانية:** حوالي 60 ساعة تشغيل شهرياً لحساب GitHub الشخصي؛ يتوقف بعد 30 دقيقة دون استخدام (يعود عند فتحه)، ويُحذف بعد 30 يوماً دون استخدام مع بيانات التجربة التي فيه.

## 2) من جهازك برابط مؤقت (Cloudflare) — لعرض التجربة على آخرين

1. شغّل `Start-Madar-Trial.bat` وانتظر حتى يفتح النظام.
2. شغّل **`Share-Trial-Link.bat`** (أول مرة ينزّل أداة Cloudflare مرة واحدة).
3. يظهر في النافذة مربع فيه رابط مثل `https://xxxx-xxxx.trycloudflare.com` — انسخه وأرسله.

- يعمل الرابط ما دامت النافذتان مفتوحتين والجهاز يعمل، ويتغير في كل تشغيل.
- لا يحتاج حساباً ولا إعدادات راوتر.
- الرابط يعمل مع **التجربة فقط** (`Start-Madar-Trial.bat`)؛ النسخة الحقيقية لا تقبله.
- لإيقاف المشاركة: أغلق نافذة `Share-Trial-Link.bat`.

## 3) رابط ثابت للتجربة حتى النشر

يحتاج خادماً صغيراً ودوميناً (انظر `hosting-advice-ar.md`)، ثم أمر واحد `deploy/install.sh`. هو نفسه مسار النشر النهائي، فالأفضل البدء به عند اختيار مزود الخادم.

## الأمان
- النظام يقبل التعديلات من روابط التجربة المؤقتة فقط عندما تعمل نسخة التجربة (`TRIAL_LINKS=1`)، ويبقى تسجيل الدخول ورمز الحماية (CSRF) مطلوبين لكل عملية.
- لا تستخدم الرابط العام أو رابط Cloudflare مع البيانات الحقيقية.
