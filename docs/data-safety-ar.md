# حماية البيانات والعمل — أين يُحفظ كل شيء

## ثلاثة أشياء مختلفة

| ماذا | أين يُحفظ | كيف يُحمى |
|---|---|---|
| **الكود والمستندات** (النظام نفسه) | GitHub: المستودع `mohasker/School-Accountant`، الفرع `claude/vibrant-bell-tj6ext` (الفرع الافتراضي) | كل نسخة مسجلة برقم ولا تُحذف؛ الإصدارات (Releases) نقطة ثابتة يمكن تنزيلها دائماً، مثل `v0.0.0` |
| **بياناتك الحقيقية** (المعاملات والعهد والمرفقات) | جهازك فقط: مجلد `.data\moesas` | النسخ الاحتياطية من لوحة مدير النظام + «مجلد نسخة ثانية» (فلاشة أو OneDrive) |
| **ملف الأسماء المحلي** | جهازك: `scripts\seed-people.local.json` | لا يُرفع إلى GitHub أبداً؛ احفظ نسخة منه مع النسخ الاحتياطية |

## رسالة GitHub عن حذف البيانات

الرسالة تخص **GitHub Codespaces**: بيئة التجربة الأونلاين (`humble-space-tribble…`) التي فُتحت للتجربة السريعة في 28 سبتمبر. GitHub يحذف أي Codespace لم يُستخدم 30 يوماً.

- ما يُحذف: **جهاز التجربة الأونلاين وبياناته التجريبية فقط**.
- ما لا يُحذف: **الكود** (في المستودع)، و**بياناتك على جهازك**، و**الإصدارات**.
- الفرع `humble-space-tribble-…` على GitHub قديم (28 سبتمبر) وكل ما فيه موجود في الفرع الحالي؛ لا خسارة.
- إذا أردت الاحتفاظ به: افتح github.com/codespaces واضغط «Keep codespace»، أو اتركه يُحذف دون أي أثر على النظام.

## المستودع عام (Public)

المستودع حالياً **عام**: أي شخص يمكنه رؤية الكود، و**سجل الشهادات السابقة** (المدارس والموردون والمبالغ) الموجود في `scripts/legacy-certificates.json` و`scripts/history-data.json`. أسماء الأشخاص غير موجودة فيه.

**يُنصح بجعله خاصاً (Private):** github.com/mohasker/School-Accountant ← Settings ← General ← أسفل الصفحة «Danger Zone» ← Change repository visibility ← Make private. لا يؤثر ذلك على عمل النظام ولا على `Upload-To-GitHub.bat` (يطلب تسجيل الدخول).

## قائمة الحماية

1. **الإصدار** `v0.0.0` على GitHub (Releases) — تنزيل النظام كما هو في أي وقت.
2. احفظ ملف ZIP لكل إصدار في OneDrive أيضاً.
3. على جهازك: «مجلد نسخة ثانية» في شاشة النسخ الاحتياطية، واختبار «استعادة» مرة على نسخة التجربة.
4. اجعل المستودع خاصاً.
5. لا تضع البيانات الحقيقية على GitHub أبداً (`Upload-To-GitHub.bat` يمنع ذلك تلقائياً).
