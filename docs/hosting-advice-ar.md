# أين يُنشر النظام؟ — توصية الاستضافة

## GitHub ليس مكاناً لتشغيل النظام
- GitHub يحفظ **الكود** والإصدارات فقط. GitHub Pages يعرض صفحات ثابتة ولا يشغّل خادماً ولا قاعدة بيانات.
- Codespaces بيئة تطوير مؤقتة تُحذف بعد 30 يوماً بلا استخدام — لا تصلح للبيانات الحقيقية.
- لذلك: GitHub = حفظ الكود، والتشغيل على **خادم (Host) بدومين**.

## الخيارات

| الخيار | مناسب لـ | التكلفة التقريبية | ملاحظات |
|---|---|---|---|
| **جهاز Windows** (`Start-Madar.bat`) | محاسب واحد | لا شيء | البيانات على الجهاز فقط؛ لا مشاركة ولا مراقب مالي عن بعد |
| **خادم سحابي (VPS) + دومين** — الموصى به | عدة محاسبين ومراقبين ومدير نظام | الخادم 15–40 دولاراً شهرياً، الدومين 10–15 دولاراً سنوياً | `deploy/install.sh` جاهز: Docker، HTTPS تلقائي، نسخة احتياطية كل ليلة |
| **خادم داخل شبكة الوزارة** | التعميم الرسمي | حسب إدارة تقنية المعلومات | الأفضل للبيانات الحكومية؛ يحتاج موافقة وفريق تقنية المعلومات |

## حجم البيانات (تقدير)
- السجلات نفسها (معاملات، عهد، موازنات، شهادات) صغيرة: **أقل من 1 جيجابايت سنوياً** حتى لـ 300 مدرسة.
- الذي يكبر هو **المرفقات الممسوحة** (PDF والصور): مثلاً 300 مدرسة × 100 ملف سنوياً × 2 ميجابايت ≈ **60 جيجابايت سنوياً**.
- البداية: خادم بـ **2 معالج، 4–8 جيجابايت ذاكرة، 80–160 جيجابايت قرص**، مع إمكانية زيادة القرص لاحقاً أو نقل الأرشيف إلى OneDrive (مدعوم في النظام).

## أين يكون الخادم؟
- البيانات مالية حكومية: يُفضَّل أن تبقى **داخل قطر**. الخيارات: **Microsoft Azure — منطقة Qatar Central**، أو **Google Cloud — منطقة الدوحة**، أو مزود محلي (Ooredoo / Vodafone Cloud).
- مزودون خارجيون أرخص (Hetzner، DigitalOcean) مناسبون **للتجربة ببيانات تجريبية** فقط ما لم توافق الجهة.
- **قبل وضع بيانات حقيقية على أي خادم خارج الوزارة: موافقة كتابية من إدارة تقنية المعلومات / الأمن السيبراني.**

## الدومين
- اسم مثل `moesas.qa` يحتاج تسجيلاً عبر مسجل `.qa` معتمد (قد يتطلب سجلاً تجارياً)، أو `moesas-qatar.com` أسهل وأسرع.
- النظام يستخرج شهادة HTTPS تلقائياً عند الربط بالدومين.

## خطة مقترحة
1. **الآن**: استمر على جهازك (`Start-Madar.bat`) مع «مجلد نسخة ثانية» في النسخ الاحتياطية.
2. **تجربة مشتركة (شهر)**: خادم Azure Qatar Central أو خادم تجريبي + دومين، 3–5 محاسبين ومراقب واحد، ببيانات حقيقية بعد الموافقة.
3. **التعميم**: نقل الخادم إلى شبكة الوزارة أو حساب سحابي باسم الجهة، مع النسخ الاحتياطي اليومي واختبار الاستعادة الشهري (`deploy/restore-test.sh`).

خطوات التثبيت على الخادم: `deployment-guide-ar.md` (المرحلة 2) و`shared-server-ar.md`.
