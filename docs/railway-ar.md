# التجربة العملية على Railway — بدون إدارة سيرفر

Railway يبني النظام من GitHub ويشغّله برابط HTTPS ثابت. الإعدادات جاهزة في `railway.json` (البناء بـ Dockerfile وتشغيل نسخة التجربة)، والمطلوب منك ضبط 4 أشياء مرة واحدة.

## 1) إنشاء المشروع
1. railway.com ← **Login with GitHub**.
2. **New Project ← Deploy from GitHub repo** ← اختر `School-Accountant` (اسمح لـ Railway بالوصول للمستودع؛ يعمل مع Private).
3. افتح الخدمة ← **Settings ← Source ← Branch**: `claude/vibrant-bell-tj6ext`.

## 2) المتغيرات (Variables)
في تبويب **Variables** ← **New Variable** أضف:

| الاسم | القيمة | لماذا |
|---|---|---|
| `DEMO_PASSWORD` | كلمة مرور قوية 12 حرفاً أو أكثر من اختيارك | كلمة مرور حسابات الإدارة admin / accountant / supervisor (لك وحدك) |
| `RAILWAY_RUN_UID` | `0` | ليستطيع النظام الكتابة في مخزن البيانات |
| `WITH_CLAMAV` | `false` | بناء أسرع (فحص الفيروسات غير مستخدم في التجربة) |

## 3) مخزن البيانات (Volume) — مهم
بدونه تُمسح بيانات التجربة مع كل تحديث.
- في صفحة المشروع: زر الفأرة الأيمن على الخدمة (أو `Ctrl+K`) ← **Add Volume** ← **Mount path**: `/app/.data`.

## 4) الرابط
- **Settings ← Networking ← Generate Domain** ← المنفذ (Port): **3000**.
- يظهر رابط مثل `https://school-accountant-production.up.railway.app` — هذا رابط التجربة.

ثم **Deploy**. أول بناء 5–15 دقيقة؛ في **Deployments ← Logs** انتظر سطر `Ready in`. ادخل بـ **زائر / 112233** وعمّم الرابط.

## دومينك الخاص (اختياري)
1. **Settings ← Networking ← Custom Domain** ← اكتب `trial.دومينك.com` ← المنفذ **3000**.
2. Railway يعطيك سجل **CNAME** (وأحياناً سجل TXT للتحقق): أضفه في DNS عند Cloudflare أو هوستينجر. في Cloudflare اجعله **DNS only** (السحابة رمادية).
3. أضف المتغير `WEB_ORIGINS` = `https://trial.دومينك.com` (بدون / في الآخر).
4. شهادة HTTPS تصدر تلقائياً خلال دقائق.

## التشغيل اليومي
- **التحديث**: كل إصدار جديد على الفرع يُبنى ويُنشر تلقائياً، والبيانات تبقى في المخزن.
- **إعادة التجربة من البداية**: احذف الـ Volume وأنشئه من جديد بنفس المسار ثم **Redeploy**.
- **نسخة احتياطية**: من لوحة مدير النظام ← النسخ الاحتياطية ← «نسخة الآن» أسبوعياً، وتنزيلها.
- **التكلفة**: خطة Hobby اشتراك شهري صغير يشمل رصيد استخدام، والزيادة حسب الذاكرة والمعالج الفعلي. راقب **Usage** أول أسبوع، ويمكن وضع حد أقصى للصرف من **Account ← Usage**.

> للتجربة فقط. البيانات الحقيقية لا توضع على Railway (سيرفرات خارج قطر) قبل موافقة إدارة تقنية المعلومات.
