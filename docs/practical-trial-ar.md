نسخة للعمل الفعلي على **بيانات تجريبية** قبل النشر الرسمي، بحساب مشترك واحد يُعمَّم على المجربين.

## الحساب المشترك

| | |
|---|---|
| اسم المستخدم | **زائر** (أو `guest` بالإنجليزية) |
| كلمة المرور | **112233** |
| الصلاحية | محاسب على مدارس التجربة (تكليفات، عروض، شهادات، عهد، تقارير) |

- الحساب يُنشأ تلقائياً عند كل تشغيل للتجربة إن لم يكن موجوداً.
- لا يمكن تغيير كلمة مروره من داخل النظام (حتى لا يغلقه مجرب على الباقين).
- كل من يدخل به يرى نفس البيانات ويعدّل عليها؛ سجل التدقيق يسجل الموقع والوقت لكل دخول.
- حسابات الإدارة للتجربة تبقى: `admin` / `accountant` / `supervisor` بكلمة المرور `Madar-Trial-2026` — لا تُعمَّم.

## التشغيل (التنشيط)

**أ) من GitHub بدون تثبيت (Codespaces)**
1. افتح https://codespaces.new/mohasker/School-Accountant?quickstart=1 وسجّل الدخول بحساب GitHub ← **Create codespace**.
2. انتظر 3–5 دقائق أول مرة؛ يفتح النظام في تبويب رابطه ينتهي بـ `-3000.app.github.dev`.
3. للمشاركة: تبويب **PORTS** ← المنفذ 3000 ← زر أيمن ← **Port Visibility ← Public** ← انسخ العنوان وعمّمه.
4. حدود مجانية: ~60 ساعة شهرياً، يتوقف بعد 30 دقيقة دون استخدام (يعود عند فتحه من github.com/codespaces)، ويُحذف بعد 30 يوماً دون استخدام.

**ب) من جهازك (Windows) برابط مؤقت**
1. فك ضغط الإصدار وشغّل `Start-Madar-Trial.bat` وانتظر فتح النظام.
2. شغّل `Share-Trial-Link.bat` ← انسخ رابط `https://….trycloudflare.com` الظاهر وعمّمه.
3. الرابط يعمل ما دام الجهاز والنافذتان مفتوحة، ويتغير في كل تشغيل.

**ج) رابط ثابت** (لتجربة تمتد أسابيع): خادم صغير + دومين ثم `deploy/install.sh` — انظر `hosting-advice-ar.md`.
